# Third-party licences

Everything StampGrade ships is either written in this repo or listed below.

## GSAP 3 (with ScrollTrigger)

**Standard "No Charge" GSAP License** — https://gsap.com/standard-license

Since Webflow's acquisition (30 April 2025) GSAP and **all** of its plugins are
free for commercial use. "Permitted Uses" covers implementation on any website,
web application or digital interface, by any person or entity. There is no
revenue condition and no Club membership requirement.

The only carve-out is "Prohibited Uses": you may not use GSAP to build a
no-code tool that competes with Webflow's visual animation builder. StampGrade
grades websites; it is not an animation builder, so it is squarely inside
Permitted Uses on every tier, paid ones included.

> Correction: an earlier commit message on this repo claimed the free licence
> was conditional on end users not being charged, and that our paid tiers would
> need a Business Club membership. That was wrong. The clause it quoted is
> legacy text that survives only inside an HTML comment in the licence page's
> source; it is not part of the live licence. No membership is required.
